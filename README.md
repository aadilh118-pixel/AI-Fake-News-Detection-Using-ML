# AI-Fake-News-Detection-Using-ML

##  Project Overview
This project is an AI/ML-based Fake News Detection system that classifies news as REAL or FAKE using Natural Language Processing (NLP) techniques.

The model analyzes text data and predicts whether the news content is trustworthy or misleading.

---

##  Features
- Fake vs Real news classification
- Text preprocessing using NLP
- Machine Learning model training
- Data visualization
- Accuracy evaluation

---

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Matplotlib

---

##  Dataset
Dataset contains labeled news articles categorized as:
- Fake News
- Real News

---

##  Project Workflow
1. Data Collection
2. Data Cleaning
3. Text Preprocessing
4. Feature Extraction
5. Model Training
6. Prediction & Evaluation

---

##  Model Accuracy
Accuracy achieved : 96.7
